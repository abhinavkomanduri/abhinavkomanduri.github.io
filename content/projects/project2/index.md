### Description
In this project, I will develop a compact cardiac monitoring system using the AD8232 analog front-end in a two-electrode configuration. By leveraging AC leads-off detection and virtual ground biasing via high-impedance resistors, I aim to eliminate the need for a right leg drive electrode. The electrodes will be placed in a modified Lewis Lead configuration on the sternum to emphasize atrial signals. This design will prioritize minimal hardware complexity while maintaining reliable signal acquisition for heart rate monitoring or arrhythmia detection.
